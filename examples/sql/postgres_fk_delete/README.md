# PostgreSQL foreign-key delete probe

**Author: Sandeep Belgavi**

A runnable companion to *Why Deleting One PostgreSQL Row Can Scan the Child Table* (aicassindra.com). Deletes an unreferenced parent row with and without an index on the referencing column.

## Prerequisites

- PostgreSQL 18 with `psql`, and a new disposable database. Nothing else is installed.

## Sample input

Generated by the script: two synthetic orders and 100,000 order lines, all on order 1.

## Commands

```
psql -v ON_ERROR_STOP=1 -d disposable_fk_demo -f foreign_key_fixture.sql
```

## Expected output

The author has not recorded a run of this script, so no plan or timing is published here. A local attempt failed before the first query because the machine had exhausted its commit memory. When you run it, compare the `Trigger for constraint order_line_order_id_fkey` line and the buffers in the two plans, and confirm the delete still succeeds for the unreferenced order.

## Limitations

Timings depend on the machine, cache state and settings, so treat them as one run. The script creates tables and an index, so use only a disposable database.
